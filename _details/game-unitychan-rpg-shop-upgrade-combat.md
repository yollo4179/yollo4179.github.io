## 문제와 구현

같은 종류의 무기라도 강화 단계와 추가 옵션이 다르면 서로 다른 아이템이다. 그래서 강화 대상은 아이콘의 종류가 아니라 인스턴스 ID로 찾는다. 상점과 인벤토리는 한 번에 하나의 구매·판매 대상을 가리켜야 해 선택 표시를 공유한다.

무기 강화 슬롯에 아이콘을 놓으면 아이콘의 인스턴스 ID로 무기를 찾아 강화 레벨에 따른 추가 옵션을 적용한다. 강화 수치에 맞는 이펙트를 표시하고, 이펙트가 끝나기 전에는 강화 버튼을 다시 누르지 못하게 했다. 상점과 인벤토리는 선택 표시를 공유해 구매·판매 대상이 동시에 두 개 선택되지 않도록 한다.

스킬과 소비 아이템은 같은 퀵 슬롯에 올릴 수 있다. 사용자가 슬롯 번호를 누르면 슬롯의 아이콘 타입을 확인한다. 소비 아이템이면 사용 로직을 호출하고, 스킬이면 플레이어를 스킬 사용 상태로 바꾼다. 기본 공격은 Animator의 공격 순서 값과 트리거를 사용해 다음 콤보 단계를 선택한다.

## 입력에서 상태 변화까지

강화 슬롯에 무기 아이콘을 놓으면 시스템은 인스턴스 ID로 실제 무기를 찾고 레벨에 따른 옵션을 적용한다. 강화 이펙트가 끝나기 전에 버튼을 다시 누르면 한 번의 연출에 여러 번 상태가 바뀔 수 있으므로, 코루틴이 이펙트를 마친 뒤 버튼을 다시 활성화한다.

퀵 슬롯은 아이콘 타입으로 소비 아이템과 스킬을 분기한다. 소비 아이템은 사용 로직으로, 스킬은 플레이어의 스킬 사용 상태로 연결한다. 기본 공격의 다음 단계는 Animator의 `AttackNO`와 공격 트리거를 함께 사용한다. 입력, 슬롯의 데이터, 캐릭터 상태와 애니메이션 단계가 각각 어느 값을 바꾸는지 분리한 구성이다.
